CHICHI SAFARIS – QUICK SETUP
============================

1. FIREBASE
   - Create project at https://console.firebase.google.com
   - Enable Authentication → Email/Password
   - Create a user (your admin login)
   - Create Firestore database
   - Register a Web app → copy config into js/firebase-config.js

2. CLOUDINARY
   - Sign up at https://cloudinary.com
   - Copy Cloud name from dashboard
   - Settings → Upload → Upload presets → Add preset
   - Signing mode: UNSIGNED
   - Put cloud name + preset name in js/firebase-config.js

3. FIRESTORE RULES (Firebase Console → Firestore → Rules)
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /itineraries/{doc} {
         allow read: if true;
         allow write: if request.auth != null;
       }
       match /gallery/{doc} {
         allow read: if true;
         allow write: if request.auth != null;
       }
     }
   }

4. RUN LOCALLY
   npx serve .
   Open http://localhost:3000
   Admin: http://localhost:3000/admin.html

5. DEPLOY
   - Netlify: drag the folder onto netlify.com/drop
   - Vercel: vercel --prod
   - Firebase Hosting: firebase init hosting && firebase deploy
